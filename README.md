# 钢铁旷野 · Steel Wilderness

**一款 Windows 2D 俯视视角陆空载具作战游戏。**

从早期轻型坦克到现代主战坦克，从螺旋桨飞机到喷气式战斗机与武装直升机：选择国家、研发载具、搭配弹药和挂载，与 AI 队友或局域网好友共同作战。

**[下载游戏](https://github.com/yinghuiyang737-code/NO-war-of-thunder/releases) · [反馈问题](https://github.com/yinghuiyang737-code/NO-war-of-thunder/issues)**

## 下载与开始

1. 在 [Releases](https://github.com/yinghuiyang737-code/NO-war-of-thunder/releases) 中下载 `SteelWilderness.exe`。请选择发布附件中的 EXE，源码压缩包不能直接作为游戏运行。
2. 将 EXE 放进一个可以正常保存文件的独立文件夹，双击启动。无需安装 Python、War Thunder 或 FMOD SDK。
3. 在车库选择国家，将已解锁载具加入出战栏，点击“出战”。
4. 在部署界面选中载具，配置携带弹药，再选择己方蓝色部署点并确认部署。

游戏持续更新，具体可用内容以所下载版本及其发布说明为准。

## 你能玩到什么

### 国家科技树与载具编成

- **中国、苏联／俄罗斯、德国、美国、日本、英国、法国**，以及单独标明的**架空系**。
- 陆战包括轻型／侦察载具、主战坦克、重型坦克、坦克歼击车、防空车和自行火炮等路线；航空包括固定翼飞机和直升机。
- 各国科技树从早期载具延伸至现代，不同载具有各自的外形、武器、弹药、机动与设备配置。
- 每套编成最多 **12 个槽位**，坦克、飞机和直升机共用；不需要的槽位可以留空。
- 科技树按权重递增排列，前置载具位于后继上方。高级载具通过每日任务奖励获得，领取后出现在对应国家、等级的科技树侧栏。
- 战斗权重按编成中最高权重计算，低权重载具混入高权重编成也会进入较高级战斗。

### 地面作战

**命中位置比单纯命中更重要。** 载具没有通用血条，发动机、传动、履带、炮管、炮闩、装弹机构、弹药架及乘员的状态会影响战斗能力。

- 装甲角度、跳弹、击穿破片、模块吸收与车内破片反弹参与伤害计算；乘员数量及车内布局按车型区分。
- 部署前可调整主武器的弹种和各自数量，总和不能超过载弹量；机枪弹药单独计算。战斗下方显示弹种、类型与余量。
- 单侧履带损坏时，另一侧仍可提供动力；部分载具具备稳定器、夜视仪、热成像、双流传动等设备。
- 可使用载具配备的烟雾弹、发动机烟幕、侦察无人机、个人弹药箱与火炮模式。
- 在己方已占领、无争夺的据点内停车可以补给弹药，缺员时每车整场最多补回一名乘员。
- 分体防空以雷达车部署，再放置最多两辆发射车；可切换控制车辆，未接管车辆停车并参与联动。

### 飞机与直升机

航空载具参加同一场陆战，使用共同出战栏和陆战研发点。

- **固定翼飞机从战区外机场起飞**，需要控制油门并手动拉升高度；鼠标指导航向，机体随转向滚转，也可主动滚转。
- **直升机从圆形停机坪起飞**，WASD 控制带惯性的位移，鼠标控制朝向，支持悬停和高度控制。
- 可用挂载按机型区分，界面显示武器类型与制导方式，包括机炮吊舱、火箭、炸弹、空空导弹和对地导弹等。
- 不同载具有不同雷达、量程、扫描方式及告警设备；雷达扫描、目标速度方向、热诱弹和箔条参与空中交战。
- 选择红外空空导弹后，可用右键开启鼠标指向导引头：大圆为搜索范围，小圆为锁定区域，锁定后变色并跟随目标。
- 支持最后发射导弹的跟随视角；部分直升机制导导弹可在导弹视角中用鼠标引导。
- 在友方机场附近可申请自动降落，落地后维修并补充弹药，再移至起飞位置；减速板、减速伞和阻拦钩按载具设备使用。

设备不是所有载具通用的。没有相应雷达、告警器、热成像或武器的载具，不能使用对应功能。

### 战场与胜负

- 每方 **16 个作战席位、5000 队伍分数**，AI 会补充队伍并在损失载具后重新部署。
- 地图随机选择，包含野外、秋季、冬季城市和大面积沙漠，采用每方双部署点、单点或三点占领布局。
- 草地、树林、建筑、砂岩、水域和烟幕影响交战；树木可被撞倒或击倒，履带会留下行驶痕迹，冬季地图会留下雪痕。
- 昼夜随机，夜战出现概率较低。深水会威胁非两栖车辆，两栖载具可正常渡水。
- 击毁载具、争夺据点与控制点位会影响队伍分数；命中、有效损伤、击毁和助攻可以获得个人得分。
- 玩家死亡后等待再部署期间，战斗继续运行。按住 Tab 可查看双方玩家及 AI 的战绩。
- 支持开局选择“中途加入对局”，进入已有战况的战斗。
- 个人得分达到 **2500 分**可申请核弹任务机；AI 也需要独立获得足够分数。核弹机可被击落，出动时全场播放警报。

## 和好友一起玩

支持 **最多 4 人局域网小队**。

1. 所有人使用同一游戏版本，连接同一局域网。
2. 一人进入“局域网小队”创建房间，其他人输入主机地址加入。
3. 各自选择编成并准备，所有人准备完成后由主机开始。
4. 对局采用全队最高载具权重；世界模拟、命中与得分由主机统一处理。
5. 自己的出战载具全部损失后，可以观战存活队友。

无法连接时，请先检查版本、主机地址及 Windows 防火墙是否允许游戏通过专用网络。当前联机功能以局域网为主。

## 自定义声音与语言

游戏内置基础音效和播放库，**没有安装 War Thunder 也能播放基础声音**。可在“声音／自定义语言包”中调节音量、切换语言、试听及查看导入状态。

### 音效／语音包

将自定义包解压后放入 **EXE 旁的 `sound` 文件夹**，可以保留包内子文件夹；游戏会自动扫描。

```text
游戏文件夹/
├─ SteelWilderness.exe
└─ sound/
   └─ 你的语音包/
      ├─ crew_dialogs_ground.bank
      └─ crew_dialogs_ground.assets.bank
```

- 支持自定义 WAV、OGG、MP3，以及兼容的 War Thunder FMOD `.bank` 音效包。
- BANK 包应保留作者提供的配套文件；只有 `.assets.bank` 往往不足以建立事件映射。
- 自定义包优先播放，未覆盖或加载失败的事件回退基础声音；也可在设置中拖入文件或文件夹。
- 车组开战、装填、战果及飞机告警会按对应事件调用；飞机命中与击杀音效目前关闭。
- 不同音效包的事件、参数和制作版本存在差异，不能保证所有 WT 音效包及其中每个事件都能原样工作。请通过游戏内导入状态与试听确认。

### 界面文字

可导入 JSON 文字语言包或兼容的 War Thunder CSV，也可从设置中导出模板再编辑。译文中的 `{0}`、`{1}` 等动态占位符应保留。

文字翻译与语音是两项独立设置；更改文字语言不一定会更改车组语音。两款游戏的文字键不同，WT 专有界面条目不会全部匹配。

## 存档与自动更新

进度和设置保存在 EXE 旁边，常用文件包括：

| 文件／文件夹 | 内容 |
| --- | --- |
| `玩家进度.json` | 已研发载具、研发点、出战编成等进度 |
| `弹药配载.json` | 各载具的弹种与携带数量 |
| `按键设置.json` | 自定义按键与触发方式 |
| `游戏设置.json` | 帧率上限、帧率显示、多核设置 |
| `音频与语言设置.json` | 音量、语音与文字语言设置 |
| `sound/` | 你的自定义音效和语言包 |

**迁移或备份游戏时，请保留这些文件以及其他已有存档文件。**

游戏会在后台检查本仓库的 GitHub Releases。发现更新后先下载并校验，完成后才提示“重启更新”；确认后退出游戏、替换 EXE 并重新启动。自动更新保留进度、按键和自定义音效，替换失败时保留或恢复旧版。

未联网或检查失败时仍可继续玩。需要手动更新时，关闭游戏后用新 EXE 替换原文件即可，保留原来的存档和 `sound` 文件夹。

## 设置与常见问题

**帧率不稳定怎么办？** 先在设置里查看游戏自身 FPS，可选择帧率上限或“无限制”，并调整多核工作进程数量。战局密度、视野、热成像和硬件会影响性能；调成无限制不代表一定能达到更高帧率。

**为什么 NVIDIA 性能叠加层显示 N/A？** 叠加层识别取决于驱动和呈现方式，目前不能保证所有机器都能显示 FPS；可使用游戏内帧率显示。

**为什么同一种导弹不能像另一种那样锁定？** 红外、半主动雷达、主动雷达、激光与指令制导的条件不同，请查看挂载旁的制导类型，以及载具是否具有相应设备。

**语音包没声音怎么办？** 检查是否已解压、是否放在当前 EXE 旁的 `sound` 中、配套 BANK 是否完整，并查看设置中的导入状态。仅放在另一份游戏目录中不会自动应用到当前游戏。

**遇到报错或异常怎么反馈？** 在 [Issues](https://github.com/yinghuiyang737-code/NO-war-of-thunder/issues) 中说明游戏版本、使用载具、地图、单人或联机、复现步骤，并附报错文字或截图。性能问题请同时提供 CPU、显卡、分辨率和游戏内 FPS。
