# NO-war-of-thunder

**Steel Wilderness（钢铁旷野）**是一款 Windows 2D 俯视视角载具作战游戏，包含陆战、飞机、国家科技树与最多 4 人的局域网小队。

项目仓库：[yinghuiyang737-code/NO-war-of-thunder](https://github.com/yinghuiyang737-code/NO-war-of-thunder)。本项目为独立游戏，与《War Thunder》及其开发商没有隶属关系。部分公开载具资料参考 War Thunder 官方 Wiki；未公开性能及二维战斗效果使用游戏模拟参数。

## 下载与运行

从仓库的 [Releases](https://github.com/yinghuiyang737-code/NO-war-of-thunder/releases) 下载 **SteelWilderness.exe**，放在可写入的文件夹中运行。无需另行安装 Python。首次启动可能需要允许 Windows 防火墙访问专用网络，局域网小队使用该网络连接。

开发目录中的交付文件固定为 `outputs/SteelWilderness.exe`。更新继续覆盖这个名称，交付目录只保留一个游戏 EXE。

玩家进度保存在 EXE 旁的 `玩家进度.json`，按键设置保存在 `按键设置.json`。迁移游戏文件夹时请一同保留这两个文件。自动更新仅替换游戏 EXE。

## 游戏内容

- 美国、苏联／俄罗斯、德国、中国、日本的陆战与飞机科技树；同一国家的载具可以编入共用的 8 个出战槽位。
- 载具权重决定分房；局域网小队采用全队最高权重。
- 每方 16 个作战席位、5000 队伍分数；野外与城市地图随机选择，包含双部署点与单／三占领点布局。
- 模块与乘员损伤、装甲角度、跳弹、击穿破片、烟雾、浅水与深水、可倒伏树木及城市掩体。
- 配备重型爆反的载具有概率偏转或折断 APFSDS 弹杆；爆反区块引爆后消耗，具体概率和后效是游戏模拟值。
- 部分轻型／侦察载具配备侦察无人机，支持目标标记和友军击毁后的侦察助攻。
- 飞机从远离战区的机场起飞，支持载具对应的挂载、雷达、告警、干扰弹及机场自动降落补给。
- 每日任务与随机高级载具奖励；个人得分达到 2500 分可以申请核弹任务。

| 地面载具 | 缩放视角 | 鼠标滚轮 |
| 地面载具 | 机枪 | Ctrl |

无人机续航为 90 秒，电量耗尽后需要 60 秒重新部署。目标标记持续 45 秒；标记期间目标被友军击毁，侦察者获得 75 分，自己击毁不会额外获得侦察助攻。地面炮弹命中得 5 分，造成模块损伤得 15 分，机枪命中得 1 分；同一目标、同类武器每秒最多计分一次。

## 局域网小队

1. 所有玩家连接同一局域网，并使用同一游戏版本。
2. 主机在主界面进入“局域网小队”，创建房间。
3. 其他玩家输入主机地址加入；房间最多容纳 4 名玩家。
4. 所有人准备后，主机开始战斗。世界模拟、命中和得分由主机判定。
5. 玩家全部载具损失后，可以观战存活队友。

## 自动更新

游戏当前版本：**2026.10.11.3**。

运行打包后的游戏时，会在后台检查本仓库最新的正式 GitHub Release。发现更高版本后自动下载，在主界面显示“重启更新”。点击后游戏退出，更新程序等待游戏关闭，再替换 EXE 并重新启动。下载大小、Windows 程序格式和 GitHub 提供的 SHA-256 摘要都会校验；下载失败可以重试，替换或启动失败时尝试回退旧版。存档和按键文件不参与替换。

未联网、仓库尚未发布正式版本或更新失败时，现有游戏仍可运行。源码自检不会联网检查更新。


先验证内部打包文件，再替换 `outputs/SteelWilderness.exe`。自检不导出预览图片，更新交付时保留玩家进度与按键设置，清理旧 EXE 和临时构建文件。
